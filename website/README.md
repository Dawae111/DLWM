# DLWM project page

Run `npm ci` in this directory. Use `npm run dev` to preview the site at the printed local address under `/DLWM/`. Edit `src/pages/index.astro`, the Table 1 data in `src/results.ts`, or the assets, styles and browser interactions in `public/`.

Run `npm run check` and `npm run build` before publishing. The build writes a standalone static site to `dist/` and copies it into the repository’s existing GitHub Pages directory, `../docs/`. Use `npm run preview` to serve that published copy locally under `/DLWM/`. You can also open `../docs/index.html` directly.
